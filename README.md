# SIPSmart — SIP Calculator

SIPSmart is a responsive, beginner-friendly SIP calculator website created as a college minor project.

## Features

- SIP future-value calculator
- Total invested amount and estimated returns
- Year-by-year investment table
- Goal planner to estimate monthly SIP required
- SIP learning section and FAQs
- Light and dark mode
- Responsive layout for mobile, tablet, and desktop
- Built using HTML, CSS, and JavaScript

## Project Files

```text
sip-calculator/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone this project.
2. Keep all four files in the same folder.
3. Open `index.html` in a web browser.

No installation or external library is required.

## Calculation Note

The calculator uses the monthly compounding formula and assumes contributions are made at the beginning of each month.

The results are illustrative estimates only. Mutual fund returns are market-linked and are not guaranteed. This project does not provide investment advice.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Deployment on GitHub Pages

1. Create a repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings**.
4. Select **Pages** from the sidebar.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then save.
7. Wait for GitHub Pages to publish the website. The published URL will appear in the Pages settings.
